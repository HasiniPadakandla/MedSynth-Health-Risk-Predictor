## Overview:

Multi-Morbidity Risk Prediction System, a comprehensive Medical Risk Prediction Dashboard for assessing multi-morbidity risk (more than two concurrent medical conditions) using machine learning on patient health and demographic data. The system supports healthcare professionals with proactive care via real-time predictions, synthetic data generation, and batch processing

## Key Features :
### 1. **Real-time Risk Assessment**:

Intuitive interface for individual patient inputs with visual probability indicators and color-coded categories.
 
### 2. **Batch Processing**:

Upload multiple records for population health management.

### 3. **Interpretability**:

Feature importance and risk visualization for clinical decisions.

### 4. **Scalable Deployment**:

Supports clinical workflows with model validation across demographics


## Technology Stack :

### **Machine Learning:**
- Supervised/unsupervised models, CTGAN for synthetic data.
​
### **Frontend:**
- Streamlit dashboard.
​
### **Analysis:**

- PCA, statistical testing, cross-validation

## Setup Instructions

- Clone the repository and install dependencies (Python, scikit-learn, CTGAN, Streamlit).

- Prepare patient data CSV with health/demographic features.

- Run **streamlit run app.py** for the dashboard.
